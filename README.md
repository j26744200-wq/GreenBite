
# GreenBite 🌿

GreenBite is a wellness and productivity web application built with React and Vite. It brings everyday wellness tracking, healthy habits, and study organization together in one place.

## Features

- **Nutrition Calculator:** Explore nutrition information and estimates.
- **Hydration Tracker:** Keep track of your water intake.
- **Steps Tracker:** Record daily steps.
- **Meal Diary:** Organize meal entries.
- **Meal Ideas:** Explore ideas for meals.
- **Food Guide:** Learn about food and balanced nutrition.
- **Study Tracker:** Organize study sessions.
- **To-Do List:** Keep track of tasks.
- **Habit Garden:** Track habits and celebrate consistency.
- **Mood Garden:** Record moods and reflect on your day.

## Requirements

Install a compatible, supported version of Node.js and npm.

## Getting Started

### 1. Install dependencies

Open a terminal in the project directory and run:

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal.

### 3. Build the project

```bash
npm run build
```

The production build is created in the `dist` directory.

### 4. Preview the production build

```bash
npm run preview
```

### 5. Run the linter

```bash
npm run lint
```
